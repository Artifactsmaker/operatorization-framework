# Operator Library

This directory contains operatorized examples developed within the Operatorization Framework.

The purpose of these examples is to illustrate how stable knowledge structures may be represented as reusable executable operators.

Current operator categories:

* Selection Operators
* Stabilization Operators
* Evolution Operators

The operators included here are conceptual research artifacts and serve as reference implementations for future computational reasoning systems.
